# v0.4.0

Confidential Agent v0.4.0 provides the full host tooling for Alibaba Cloud
Linux 3 and deployment ZIPs for Linux x86_64 and Apple Silicon macOS. Each
edition uses the official CPU/TDX all-in-one guest from v0.3.0.

## Choose an edition

- On Alibaba Cloud Linux 3 x86_64, download `install-rpm.sh` and run
  `sudo bash install-rpm.sh`. The full RPMs support local image builds and
  deployments. One-click defaults to full on this platform and accepts
  `--edition deploy-only` for hosts dedicated to deployment.
- On supported Ubuntu, Debian, and RHEL 9 compatible x86_64 distributions,
  download `cagent-deploy-0.4.0-linux-amd64.zip`.
- On Apple Silicon macOS, download `cagent-deploy-0.4.0-darwin-arm64.zip`.

Verify the ZIP against `SHA256SUMS` and extract it. Use `./one-click.sh`
for guided deployment or `./bin/cagent --help` for the individual commands.
The ZIP includes the native deployment tools and Terraform providers. The
CLI can run immediately after extraction. When one-click needs Python and
finds no compatible interpreter, it installs its interpreter into the current
user's data directory and reuses it on subsequent runs. One-click asks before
installing a local application client for an access mode that uses one.

## Deploy the shared guest

The prebuilt guest supports OpenClaw, Hermes, Codex, OpenCode, DSH,
Claude Code, QoderCLI, and Pi. Set up Alibaba Cloud credentials and run
one-click with the desired `--harness`. The CLI verifies the trusted image
metadata and artifact digests on local import. On Linux with disk inspection
tools installed, use `--verify-disk` for additional checks of the local disk and
boot materials. Runtime TDX attestation applies to imported and reused images.

The installation guide covers the one-click and step-by-step CLI flows.
[Installation and deployment guide](https://github.com/inclavare-containers/confidential-agent/blob/v0.4.0/docs/rpm.md)
