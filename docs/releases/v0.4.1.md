# v0.4.1

Confidential Agent v0.4.1 reorganizes the installation, deployment, operations,
and AppSpec documentation. The CLI lists the existing inject command in its
help, with instructions for recovering challenge-mode instances after a reboot.
The release also corrects the CPU OpenClaw token path and documents the OpenClaw
peer interface and its protocol limits.

## Install

- Alibaba Cloud Linux 3 x86_64 uses the full RPM installer
  (`install-rpm.sh`) and its paired Shelter 0.3.2-6 package.
- Linux x86_64 uses `cagent-deploy-0.4.1-linux-amd64.zip` for deployment only.
- Apple Silicon macOS uses `cagent-deploy-0.4.1-darwin-arm64.zip`.

Verify the deployment ZIP against `SHA256SUMS`, extract it, and run
`./one-click.sh` for guided deployment.

## Shared CPU guest

The v0.4.1 host tools use the official v0.3.1 CPU/TDX all-in-one guest.
The release index points to that immutable OCI artifact. Its Shelter image
descriptor, measured boot reference values, and Rekor entry stay bound to
the original guest build.
