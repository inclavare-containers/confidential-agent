# v0.3.0

Confidential Agent v0.3.0 pairs the Alibaba Cloud Linux 3 x86_64 host RPMs with a prebuilt all-in-one guest. The guest is a complete Shelter artifact in GHCR. The GitHub Release carries the smaller metadata files needed to verify it and import it into your Alibaba Cloud account.

## Install the host tools

Download `install-rpm.sh` from the official release and run it on Alibaba Cloud Linux 3.

```bash
sudo bash install-rpm.sh --version 0.3.0
```

The installer obtains expected RPM hashes from the official release manifest. It can download the RPM bytes through the configured GitHub proxy and verifies both the file and RPM payload digests. It reuses an installed package when its version, release, architecture and payload match.

The cagent RPM installs the one-click entry points under `/usr/share/cagent/one-click` and ORAS 1.3.0 under `/usr/libexec/cagent/bin`. DNF installs the companion Shelter package and resolves system dependencies.

## Use the prebuilt guest

The one-click installer selects the prebuilt all-in-one guest by default for supported CPU harnesses. To resolve the official metadata and import the guest separately, run the following commands with Alibaba Cloud credentials configured.

```bash
/usr/share/cagent/hack/resolve-release-image.sh --output-dir ./prebuilt
confidential-agent image publish \
  --artifact "$(jq -r .oci_reference ./prebuilt/image-index.json)" \
  --image-release ./prebuilt/image-release.json \
  --release-digest "$(jq -r .release_digest ./prebuilt/image-index.json)" \
  --region cn-beijing
```

`image-index.json` records the source version and commit, the immutable GHCR reference, and the SHA-256 digest of the exact bytes of `image-release.json`. Shelter uses that digest to authenticate the release metadata. The guest's Rekor build evidence and runtime attestation serve their respective roles during verification and deployment.

## Release files

- Host packages `cagent-0.3.0-1.al8.x86_64.rpm` and `shelter-0.3.2-3.al8.x86_64.rpm`.
- Guest metadata `image-index.json` and `image-release.json`.
- cagent source RPM and offline build inputs, including vendored Rust dependencies and pinned native tools.
- `install-rpm.sh`, dependency pins, version information and build environment.
- `release-manifest.json` and `SHA256SUMS` covering the RPM pair and guest metadata.
