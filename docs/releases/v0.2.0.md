# v0.2.0

Confidential Agent v0.2.0 provides RPM packages for Alibaba Cloud Linux 3,
x86_64. The packages include the host CLI, guest daemon, gateway, PEP,
native tools and application templates.

## Install

Download `install-rpm.sh` from this release and run:

```bash
sudo --preserve-env=CA_GITHUB_PROXY_URL,CA_GITHUB_PROXY_FIRST \
  bash install-rpm.sh --version 0.2.0
confidential-agent --version
```

The installer verifies the SHA256 and RPM payload digests, then installs
`cagent-0.2.0-1.al8.x86_64.rpm` and `shelter-0.3.2-2.al8.x86_64.rpm`
together through DNF. System dependencies, including TNG 2.9.2, are resolved
from the Alinux3 repositories.

Downloads use a GitHub proxy with fallback to the official URL. Set
`CA_GITHUB_PROXY_FIRST=0` to prefer direct downloads, or set
`CA_GITHUB_PROXY_URL=""` to disable the proxy. See the
[installation guide](https://github.com/inclavare-containers/confidential-agent/blob/v0.2.0/docs/rpm.md)
for proxy configuration, manual installation and local package installation.

## Assets

- cagent and Shelter RPMs.
- cagent SRPM and a build-input archive containing source, vendored Rust dependencies and native tools.
- `install-rpm.sh` for installing the RPM pair.
- `release-manifest.json` and `SHA256SUMS` for package versions, source commit and file checksums.
- Dependency versions, native-tool pins and build-environment information.

## Changes

- Install Confidential Agent from RPMs without compiling it locally.
- Download and cache the pinned Shelter package from GitHub Releases.
- Support proxy and direct downloads with checksum verification and fallback.
- Build and test packages in GitHub Actions, including clean Alinux3 installation, native tools, application templates and package upgrades.
