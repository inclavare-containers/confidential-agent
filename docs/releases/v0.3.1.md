# v0.3.1

The prebuilt all-in-one guest uses a 30 GB base disk and a zlib-compressed QCOW2. The CPU one-click installer defaults to a 120 GiB ECS system disk. The encrypted writable layer expands on first boot.

The guest uses Node.js 24.21.0 and its bundled npm. Hermes ships with its compiled TUI and Dashboard. DingTalk 3.9.1 is installed through OpenClaw's ClawHub installer and can be enabled per instance.

## Install on Alibaba Cloud Linux 3

Download `install-rpm.sh` from this release and install the verified host package pair.

```bash
sudo bash install-rpm.sh --version 0.3.1
```

The RPM installer verifies the cagent and Shelter package files and their payload digests. The CPU one-click entry point selects the prebuilt all-in-one guest by default. To download the guest separately, run the installed image downloader.

```bash
python3.11 /usr/share/cagent/hack/download-release-image.py --output-dir ./prebuilt --region cn-beijing
```

`image-index.json` pins the OCI artifact and the digest of `image-release.json`. The release includes cagent 0.3.1, Shelter 0.3.2-5, the cagent source RPM and offline build inputs.
